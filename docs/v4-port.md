# V4.0 手势模型的 Python 到 C 移植

来自团队 2026-07-22 的移植交接包。示例保留森林推理模块，使用手写的小型决策树演示模型表与固件代码的接口。它对应 V4.0 移植工作，首页的 V4.1 回放数据来自另一个版本。

| 阶段 | 端侧需要对齐的内容 |
|---|---|
| IMU 输入 | 50 Hz、有符号 16 位原始计数、固定轴序，检查时间戳的乱序和重复 |
| 候选特征 | 在候选分段完成后提取固定顺序的 75 维特征 |
| 树模型 | 将每棵树的节点和叶节点概率导出为连续表。C 侧按特征阈值逐树遍历，再对叶节点概率取平均 |
| 事件输出 | 结合置信度和事件状态判定。双动作通过时间窗口配对，再交给结果队列与 BLE 传输 |

示例运行时使用调用者提供的输出数组，无需动态分配内存。输入模型表应来自可信导出流程，并在集成阶段校验树偏移、节点索引和模型版本。建议按「特征值、概率、最终事件」三个层次对照 Python 和 C 的结果，这样能区分输入处理、推理与状态机的偏差。

```sh
cc -std=c99 -Wall -Wextra -o v4-port-demo \
  examples/v4-port/forest_runtime.c examples/v4-port/demo.c
./v4-port-demo
```

示例覆盖阈值等号、阈值两侧和特征数不足四种输入。示例参数为合成数据，实际识别还需要特征提取、训练参数和手势状态机。
